# خماس × اليوم الوطني ٩٦ — دليل النظام الكامل

تجربة تفاعلية (كروسورد + كوبون + هدايا) تدعم أكثر من كافيه في نفس الوقت، كل واحد بثيمه وكوبوناته الخاصة، مبنية على ٣ قطع تعمل مع بعض:

```
[الزائر بجواله]
      │
      ▼
index.html  ──────►  Cloudflare Worker  ──────►  Airtable
(اللعبة نفسها،         (الوسيط الآمن،              (قاعدة البيانات:
 على Vercel)            يحمل مفاتيح الدخول)          الكافيهات + الكوبونات + التسجيلات)
```

- **`index.html`** — اللعبة الكاملة، ملف واحد، مرفوعة على Vercel. ما فيها أي كلمة سر أو مفتاح دخول.
- **`worker.js`** — طبقة حماية مرفوعة على Cloudflare Workers. هو الوحيد اللي يعرف مفاتيح Airtable.
- **Airtable** — قاعدة البيانات الحقيقية: بيانات كل كافيه، عدّاد الكوبونات، وتسجيلات الهدايا.

---

## ١. الروابط

| الرابط | لمين | يعرض وش |
|---|---|---|
| `https://your-domain.vercel.app?cafe=CAFE_ID` | الزوار (يُطبع على QR بالطاولة) | اللعبة كاملة بثيم ذاك الكافيه |
| `https://your-domain.vercel.app?cafe=CAFE_ID&owner=1` | صاحب الكافيه نفسه | عدد الكوبونات المتبقية فقط، بدون لعبة |
| `https://your-domain.vercel.app?admin=1` | خماس فقط (محمي بكلمة مرور) | كل الكوبونات + كل تسجيلات الهدايا لكل الكافيهات |

`CAFE_ID` = بالضبط نفس القيمة المكتوبة بعمود `cafe_id` بجدول `Cafes`.

## ٢. قاعدة بيانات Airtable

القاعدة: **NationalDay-Khumas96** — Base ID: `appmfIyVbj9Sj7OqF`

### جدول `Cafes` — إعدادات كل كافيه (ثيمه وكوبوناته)

| الحقل | النوع | الوصف |
|---|---|---|
| `cafe_id` | Single line text | رمز فريد بالإنجليزي، يُستخدم بالرابط (مثل `cafe1`) |
| `name` | Single line text | اسم الكافيه الظاهر للزوار |
| `primary_color` | Single line text | لون خلفية الصفحة بالكامل (Hex، مثل `#0D3B2E`) |
| `accent_color` | Single line text | لون الأزرار والشارات وعداد الوقت (Hex) |
| `highlight_color` | Single line text | لون رقم الخصم واسم الكافيه داخل بطاقة الكوبون (Hex) |
| `logo_url` | Single line text | رابط مباشر لشعار الكافيه (يظهر أعلى الصفحة) |
| `coupon_limit` | Number | عدد كوبونات القهوة المتاحة لهذا الكافيه |
| `discount_label` | Single line text | نص الخصم كامل، مثل `٢٠٪ خصم` (اكتبي علامة % بنفسك، الحقل نص عادي) |

**لإضافة كافيه جديد:** أضيفي صف واحد بهذا الجدول فقط. رابطه يشتغل فورًا، بدون أي تعديل على الكود.

### جدول `Coupons` — سجل الفوز بالكوبون (يمتلئ تلقائيًا)

| الحقل | النوع |
|---|---|
| `cafe_id` | Single line text |
| `serial` | Number |

سجل واحد لكل كوبون يُمنح. عدد الكوبونات المتبقية لأي كافيه = `coupon_limit` ناقص عدد صفوف هذا الجدول لنفس `cafe_id`. حذف صف = رجوع كوبون واحد للمخزون.

### جدول `Claims` — تسجيلات صفحة الهدايا (يمتلئ تلقائيًا، مشترك بين كل الكافيهات)

| الحقل | النوع |
|---|---|
| `service_id` | Single line text |
| `service_name` | Single line text |
| `name` | Single line text |
| `phone` | Single line text |
| `cafe_id` | Single line text |

كل صف = خدمة انحجزت. حذف الصف يرجّع الخدمة متاحة للجميع فورًا. رقم الجوال بهذا الجدول هو أساس قاعدة "خدمة واحدة لكل شخص".

**الاسم:** `khumas-waten96`

|---|---|
| `AIRTABLE_BASE_ID` | `appmfIyVbj9Sj7OqF` |
| `AIRTABLE_TOKEN` | Personal Access Token من Airtable (يبدأ بـ `pat...`)، صلاحيته محصورة بهذي القاعدة فقط |

### تحديث كود الـ Worker

عند أي تعديل على `worker.js`: Cloudflare → `khumas-waten96` → **Edit code** → امسحي الكود القديم بالكامل → الصقي الجديد → **Deploy**. الـ Secrets ما تنمسح، تبقى كما هي.

### المسارات (Endpoints) اللي يوفرها

| المسار | الوظيفة |
|---|---|
| `GET /api/cafe?id=` | إحضار ثيم وبيانات كافيه معيّن |
| `GET /api/stock?cafe=` | عدد الكوبونات المتبقية لكافيه معيّن |

| `POST /api/admin` | بيانات لوحة الإدارة أو تصفير كوبونات كافيه (يتطلب كلمة المرور) |

## ٤. ملف اللعبة (index.html) — الإعداد الوحيد المطلوب فيه

بأعلى الملف تقريبًا:

```js
const WORKER_URL = 'https://khumas-waten96.haneen1lrubaie.workers.dev';
```

هذا هو **التعديل الوحيد** المطلوب — لا يوجد أي مفتاح أو كلمة سر تُكتب بهذا الملف إطلاقًا.

### تعديل خدمات صفحة الهدايا

دوري على `const SERVICES = [` — قائمة من ١٢ خدمة، كل وحدة فيها:

```js
{ id:'photo', icon:'', title:'جلسة تصوير مجانية', provider:'اسم المصوّر', link:'https://instagram.com/username' },
```

- `title` — اسم الخدمة الظاهر بالفقاعة.
- `provider` — اسم مقدم الخدمة (يظهر كشارة على نفس الفقاعة).
- `link` — رابط حسابه، يظهر داخل نافذة التسجيل للتصفح فقط (التواصل الفعلي يصير من خماس بعد التسجيل، مو مباشر مع مقدم الخدمة).

⚠️ استبدلي القيم الحالية (placeholder) بأسماء وروابط مقدمي الخدمات الحقيقيين قبل الإطلاق.

### رابط "زوروا موقع خماس" بعد التسجيل

داخل نفس الملف، دوري على `href="https://khumas.sa"` لو احتجتي تغيّرينه.

## ٥. النشر على Vercel

1. غيّري اسم الملف إلى **`index.html`** بالضبط.
2. روحي لـ **vercel.com/drop**.
3. اسحبي الملف وأفلتيه، اختاري اسم مشروع، اضغطي **Deploy**.
4. أي تحديث لاحق: عدّلي الملف محليًا، واسحبيه فوق نفس المشروع من جديد.

## ٦. آلية اللعبة (للفهم فقط، ما يحتاج إعداد)

- **الكروسورد:** ٣ كلمات (وفاء / طموح / نخلة)، أول حرف من كل وحدة يكوّن عموديًا كلمة **"وطن"** — تنكشف فقط بعد حل الثلاث كلمات، بدون أي تلميح مسبق.
- **الفوز:** لو فيه كوبونات متبقية للكافيه، يظهر كوبون بثيم الكافيه ورقم تسلسلي ("الفائز رقم ٧ من ١٥"). لو خلصت الكوبونات، يظهر بدلها بطاقة اعتذار لطيفة.
- **إذا خلصت كوبونات كافيه معيّن ولسا فيه هدايا متاحة:** أي زائر يفتح رابط ذاك الكافيه يروح مباشرة لصفحة الهدايا (يتخطى اللعبة بالكامل) مع رسالة "انتهى تحدي اليوم".
- **خدمة واحدة لكل شخص:** يتحقق النظام من رقم الجوال (مسجّل بجدول Claims) بغض النظر عن الكافيه أو الجهاز.
- **قفل إضافي بمستوى الجهاز:** بعد ما يسجل شخص خدمة، جهازه (المتصفح) يُقفل محليًا عن أي محاولة تسجيل ثانية — طبقة حماية إضافية فوق فحص رقم الجوال بالسيرفر.
- **انتهاء كل الهدايا:** لما تُحجز كل الاثنتي عشرة خدمة، تظهر بطاقة "انتهت جميع الهدايا لهذا اليوم" بدل الفقاعات.

## ٧. الاختبار المحلي

لتصفير قفل "الهدية مستخدمة" بجهازك أثناء التجربة، أضيفي `&reset=1` على أي رابط:
```
https://your-domain.vercel.app?cafe=demo&reset=1
```
⚠️ لا تشاركي هذا الرابط مع الزوار الحقيقيين — يلغي حماية "خدمة واحدة لكل شخص" بمستوى الجهاز.

## ٨. الأمان — ملخص

- **لا يوجد أي مفتاح دخول داخل `index.html`.** كل الاتصال يمر عبر الـ Worker.
- **`AIRTABLE_TOKEN` محصور** بصلاحية القراءة/الكتابة على قاعدة واحدة فقط (`NationalDay-Khumas96`)، وليس على كامل حساب Airtable.
- **رابط `?admin=1` محمي بكلمة مرور** (`ADMIN_PASSWORD`) — لا تشاركيه ولا كلمة المرور مع أحد.
- **رابط `?owner=1`** يعرض فقط عدد كوبونات ذاك الكافيه، بدون أي بيانات عملاء أو كافيهات ثانية — آمن لمشاركته مع صاحب الكافيه.

## ٩. المشاكل الشائعة وحلولها

| المشكلة | السبب الأرجح | الحل |
|---|---|---|
| `{"found":false}` عند فحص `/api/cafe` | `cafe_id` غير موجود بجدول Cafes، أو `AIRTABLE_BASE_ID`/`AIRTABLE_TOKEN` غلط | تأكدي من الـ Base ID بالنسخ من شريط العنوان مباشرة (احذري تشابه حرف `l` و`I`) |
| خطأ `403 Forbidden` من Airtable | التوكن مربوط بقاعدة غير صحيحة، أو صلاحياته ناقصة | تأكدي إن Access بالتوكن محدد على نفس القاعدة، والـ Scopes فيها `data.records:read` و`data.records:write` |
| ألوان أو نصوص فيها رموز غريبة (`\t`, `\n`) | نسخ-لصق فيه مسافة/سطر خفي | امسحي الخانة بالكامل (Ctrl+A ثم Delete) واكتبي القيمة يدويًا |
| شارة الكوبونات ما تتحدث فورًا | الكاش بالمتصفح | اعملي Refresh (F5) للصفحة |
| "تبقى ١٥ كوبون" ما تغيّرت رغم إضافة كافيه جديد بعدد مختلف | فتحتِ رابط بدون `?cafe=` الصحيح، فرجع للثيم الافتراضي | تأكدي من `cafe_id` بالرابط مطابق تمامًا لما بـ Airtable |
